# 🌸 Flower Classification using CNN

This project demonstrates how to build a **Convolutional Neural Network (CNN)** to classify images of flowers into different categories using **TensorFlow** and **Keras**.

## 📁 Project Structure

```
📦 Flower_classification_using_cnn
 ┣ 📄 Flower_classification_using_cnn.ipynb
 ┣ 📁 dataset/ (assumed)
 ┗ 📄 README.md
```

## 🔍 Overview

- **Goal**: To classify images of flowers into their respective categories.
- **Technique**: Deep Learning with CNN (Convolutional Neural Networks)
- **Framework**: TensorFlow / Keras
- **Dataset**: Assumed to be a folder structure with subfolders for each flower class.

## 🧠 Model Architecture

- Convolutional Layers
- MaxPooling Layers
- Dropout Layers (for regularization)
- Fully Connected Dense Layers
- Activation Function: ReLU
- Output Layer Activation: Softmax

## 📊 Performance

- Metrics: Accuracy, Loss
- Visualizations: Training vs Validation Accuracy & Loss graphs

## 🚀 How to Run

1. **Clone this repository:**
   ```bash
   git clone https://github.com/yourusername/flower-classification-cnn.git
   cd flower-classification-cnn
   ```
2. **Run the Notebook:**
   Open `Flower_classification_using_cnn.ipynb` in Jupyter Notebook or Google Colab and run the cells.

## 📦 Requirements

- Python 3.7+
- TensorFlow
- Keras
- NumPy
- Matplotlib
- scikit-learn


## 📈 Results

Training and validation accuracy and loss curves are used to evaluate the model's performance. Model accuracy can be further improved with data augmentation and hyperparameter tuning.
